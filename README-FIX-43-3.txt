FIX 43.3 — Centralized Classroom Results & Teacher Dashboard
============================================================

PURPOSE
- Keep every completed interview report in localStorage on the student computer.
- Synchronize the completed report to Supabase as the official centralized classroom result.
- Let the teacher monitor 0/4 -> 4/4 candidates from one computer.
- Let the teacher press "TỔNG HỢP KẾT QUẢ" after 4/4 results are synchronized.
- Do NOT make another Gemini request for the class summary.

IMPORTANT ARCHITECTURE
Student browser -> Next.js API -> Supabase
Teacher browser -> Next.js API -> Supabase
SUPABASE_SECRET_KEY is server-only and must never be placed in browser code.

SUPABASE SETUP
1. Create/open the Supabase project.
2. Open SQL Editor.
3. Run: supabase/fix43_3_classroom_results.sql
4. In project Settings > API Keys, create/copy the server Secret key (sb_secret_...).
5. In the local project root, add to .env.local:

SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
SUPABASE_SECRET_KEY=sb_secret_YOUR_SECRET_KEY
TEACHER_DASHBOARD_PIN=choose-a-private-teacher-pin

6. Add the same three variables in Vercel Project Settings > Environment Variables for production.
7. Never commit .env.local.

TEACHER FLOW
1. Open /teacher/classroom
2. Enter TEACHER_DASHBOARD_PIN.
3. Create a class session. Default code shown in the UI is HG2026; change it if the code already exists.
4. Copy the Student Link generated by the dashboard.
5. Open that same Student Link on both student computers.
6. Dashboard auto-refreshes every 2.5 seconds.
7. When 4/4 candidates are synced, press "TỔNG HỢP KẾT QUẢ".

STUDENT FLOW
Computer 1: Candidate A -> Start Next Candidate -> Candidate B
Computer 2: Candidate C -> Start Next Candidate -> Candidate D

The class session is attached by URL:
/interview?session=HG2026

After each completed interview:
- local report saved first
- cloud sync starts
- UI shows "Synced to teacher" on success
- if network fails, local result remains and "Retry Sync" is available

FIX 43.3 CLASSROOM RELIABILITY RULE
In classroom mode, FinalRecruiterReport does NOT call /api/interview-report.
It builds the final report deterministically from the three already-evaluated answers.
This avoids an extra Gemini request on the critical classroom path.
Normal individual practice without ?session=... keeps the previous intelligent final-report behavior.
