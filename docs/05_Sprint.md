# Development Methodology

English AI Coach follows

Agile

using

Sprint-based Development.

Each Sprint focuses on one clear objective.

No Sprint should attempt to complete
too many modules simultaneously.

• Architecture changes are required

# ============================================================

The following template must be completed before
implementation starts.

------------------------------------------------------------

------------------------------------------------------------

# Sprint Goal

A Sprint must have ONE primary objective.

Examples

Complete Evaluation Module

Complete Dashboard

Complete Teacher Portal

Never define multiple unrelated objectives
inside one Sprint.

------------------------------------------------------------

# Sprint Backlog

The Sprint Backlog contains all tasks that are
planned for this Sprint.

Example

□ Design

□ Architecture Review

□ Implementation

□ Unit Testing

□ Manual Testing

□ Documentation

□ Freeze

------------------------------------------------------------

# Priority Levels

HIGH

Critical work.

Must be completed.

------------------------------------------------------------

MEDIUM

Important work.

Complete if time allows.

------------------------------------------------------------

LOW

Optional work.

Can move to the next Sprint.

------------------------------------------------------------

# Sprint Success Criteria

A Sprint is considered successful only when

✓ Primary Goal completed

✓ Build successful

✓ Manual testing passed

✓ Documentation updated

✓ Module Freeze approved (if applicable)
