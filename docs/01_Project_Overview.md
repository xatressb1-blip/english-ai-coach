# 1. Project Vision

English AI Coach is an AI-powered web application designed to help
students improve their English speaking skills through realistic
job interview practice.

The application acts as an intelligent interviewer.

It asks interview questions.

It listens to the user's answer.

It evaluates the answer using Google Gemini.

It provides professional feedback.

The ultimate goal is to help Vietnamese students become more
confident in English job interviews.

# 5. Development Philosophy

The project follows several important principles.

1.

Readable code is better than clever code.

2.

One module has one responsibility.

3.

Business Logic and UI must be separated.

4.

Never modify a Frozen module unless absolutely necessary.

5.

Every completed module must be tested before Freeze.

6.

Architecture is controlled by the Technical Leader.
